# V11 — Liens directs dans les modules

Objectif : supprimer les blocs descriptifs non cliquables.

Chaque module propose désormais :
1. Cours — un ou plusieurs liens directs vers un cours ou un chapitre ciblé ;
2. Exercices — liens directs vers exercices, QCM, TP ou banque ciblée ;
3. Évaluation — page interne spécifique au module, chronométrée, avec score ;
4. Annales — filtre automatique de la banque V10 sur le module.

Ressources particulièrement approfondies :
- Mathématiques : Maths & Tiques (Yvan Monka, Académie de Strasbourg), Math93, Éduscol.
- Physique-Chimie : PCCL et Labolycée.
- NSI : Ferney NSI, Pixees, France-IOI.
- Français : Lumni, Commentaire Composé, annales.
- Histoire-Géographie : Lumni, Éduscol, banques E3C archivées.
- Anglais : British Council / Lumni.
- Arabe : site national Langue et Culture arabes.
- Philosophie / EMC / Grand oral / EPS : Éduscol et ressources institutionnelles.

Quand une banque publique d'évaluation n'existe pas, la V11 crée une évaluation guidée interne au lieu d'inventer une « annale officielle ».
